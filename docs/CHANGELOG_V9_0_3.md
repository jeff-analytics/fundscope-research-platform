# FundScope V9.0.3 更新记录

V9.0.3 是面向 GitHub 发布前的研究交互修复版，集中解决季度播放和基金同类研究的实际可用性问题。

## 季度播放改为真正驱动研究页面

- “核心持仓”不再使用全历史固定的一组证券。每次切换或播放季度时，图例会改为当前报告期前 8 大披露持仓。
- 核心持仓曲线只展示当前报告期周边最多 12 个报告期，并标记当前季度，减少 20 多年历史造成的大量空白和断裂线段。
- “持仓排名轨迹”改为围绕当前报告期动态计算，证券集合和排名随季度同步变化，不再固定为最新 12 期。
- 深度分析中的风格漂移、规模风格、价值成长、行业集中和雷达画像都读取当前播放季度。
- 风格轨迹使用当前季度周边窗口，并标记当前报告期。
- 配置迁移估计、隐形调仓信号改为当前季度与上一季度实时计算。
- 收益缺口历史仍完整保留，但当前季度在图中会被突出显示。
- 同类定位和持仓相似属于横截面重计算，进入这两个页签后自动停止季度播放，避免每 1.2 秒触发一次大型横截面请求。

## 同类定位性能重写

- 不再复用完整 Research Explorer 计算流程。
- 新增轻量的报告期行为快照，只读取当前季度和上一季度需要的持仓字段。
- 调仓强度、前十集中度、持仓延续率采用向量化横截面计算。
- 规模风格、价值成长和风格漂移在轻量快照上批量计算。
- 横截面结果按报告期缓存，切换同一季度下的比较范围无需重复扫描数据库。
- 小样本也可以生成标准化距离，不再因为“可用维度不足 4 个”而只显示空状态。

## 持仓相似性能重写

- 先根据目标基金当前季度持仓，从数据库索引中筛出具有共同证券的候选基金。
- 只加载候选基金的当季完整持仓，不再读取整个主动偏股基金横截面。
- 仍通过 Fund Master 归并 A/C/E 等份额，避免重复基金进入结果。
- 优先展示至少 2 只共同证券的基金；极端小样本下会降级到 1 只共同证券并标记低重合，不再无解释地保持空白。

## 发布验证

- 后端自动测试 39 项通过。
- 600 只基金、2 个季度、24,000 条持仓的合成性能样本中，同类定位冷启动约 0.33 秒，缓存后约 0.02 秒，持仓相似约 0.06 秒。该数据仅用于结构性能回归，不代表用户机器上的固定耗时。
- 前端所有 TS/TSX 文件完成 TypeScript 语法解析，无语法错误。
- 用户数据库继续位于 `~/.fundscope/fundscope.db`，升级无需重新采集。

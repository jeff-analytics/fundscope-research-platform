# FundScope V9 前置对标研究

本轮对标只使用厂商官方英文资料或官方国际站，重点研究真实商用产品如何组织投资研究工作，而不是照搬视觉外观。

## 1. Koyfin

核心做法：
- Watchlist 不是静态列表，可以保存列配置、排序、分组、备注与自定义计算。
- Dashboard 可以保存、复用，并允许多个视图服务不同研究任务。
- Alert 与研究对象关联，用户在研究过程中直接创建触发条件。
- 同一研究对象可从列表、图表、Dashboard 等入口持续下钻。

FundScope V9 吸收：
- 研究收藏夹与研究笔记。
- Explorer 保存视图、重置和 CSV 导出。
- 基金/证券指标阈值监控。
- 图表、表格和全局搜索统一进入同一个研究对象。

## 2. Morningstar Direct

核心做法：
- Portfolio、Holdings、Peer、Style Analysis 位于统一研究体验中。
- Style Box 基于底层持仓特征形成组合风格，而不是依靠基金名称。
- Peer Analysis 与 Style Drift 用于识别策略相对位置和时间变化。
- 机构研究流程通常先做定量筛选，再进入经理和组合层面的深入分析。

FundScope V9 吸收：
- 同类定位基于当前报告期横截面百分位。
- 保留 P25、中位数、P75 和样本数量，不生成不可解释的综合分数。
- 基金经理 Explorer 使用其当前产品集合的持仓行为与风格统计。
- 原有 Style Drift、Security Master、Return Gap 继续保留。

## 3. OpenBB Workspace

核心做法：
- 将数据源、分析组件、权限和研究工作流放入同一 Workspace。
- 强调可治理的数据访问、角色权限、审计与可复用工作流。
- 避免每个研究需求都形成一个孤立的一次性应用。

FundScope V9 吸收：
- 新增持久化“我的研究”。
- 收藏、笔记、监控、最近访问、操作记录统一进入 Workspace。
- 本地角色分为 Research Analyst 与 Maintainer。
- 数据中心在 Analyst 角色下隐藏并在直接访问时进行权限兜底。
- 研究数据继续保存在用户本地 SQLite 中。

## 4. moomoo Desktop

核心做法：
- 桌面端强调可定制工作区、多屏和对象同步。
- 用户在观察、分析与执行之间切换时，不需要反复重新寻找研究对象。
- 快捷键和高密度桌面布局服务高频使用。

FundScope V9 吸收：
- Ctrl+K 全局对象搜索。
- Alt+1 至 Alt+6 页面切换。
- 基金、基金经理和证券统一搜索与最近研究。
- 桌面研究区与移动端底部导航分别适配。

## 5. Tiger Trade

核心做法：
- Watchlist 支持多列浏览、置顶和重点信息高效读取。
- 页面持续减少冗余信息，把高价值研究内容放到更靠前的位置。
- 订阅/提醒采用集中管理，避免用户逐页重复配置。

FundScope V9 吸收：
- Explorer 更强调横截面比较与异常发现。
- 监控集中在“我的研究”中统一管理。
- 表格中的趋势与状态优先使用紧凑、可比较表达。
- 主研究页继续清理开发式说明文案。

## 本轮明确没有照搬的内容

- 不引入交易和下单模块。
- 不使用技术指标、K 线或 Momentum 维度。
- 不做没有真实数据支撑的 AI 总结、推荐分数或机会评分。
- 不做自由拖拽 Dashboard。当前数据和研究对象结构尚未需要这一层复杂度，先保证研究工作区、保存视图与监控逻辑完整。

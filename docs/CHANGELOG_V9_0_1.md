# FundScope V9.0.1 更新记录

## 中文界面与专业记号

- 基金研究中的 Return Gap 统一改为“收益缺口”。
- 产品功能、菜单、按钮、表头、空状态、错误状态和任务状态以中文为主。
- 金融、统计和技术领域的通用记号保留行业惯例：权重变化使用 `pp`，基金对比使用“基金 A / 基金 B”，同类定位使用 `P25 / P75`，数据容量使用 `MB / GB`。
- FundScope、Ctrl / Alt、CSV、API、PE、PB、ROE、NAV、AUM、Top 10、Q1-Q4 等专业或技术缩写按场景保留。
- 左侧版本标识为“第 9.0.1 版”。
- 浏览器标题为“FundScope｜基金研究工作区”。
- Windows 与 macOS 启动过程中的状态提示使用中文。
- FastAPI 服务标题为“FundScope 接口服务”。

## 功能完整性

继承 V9.0.0 全部研究工作区能力，包括研究探索、基金/证券/基金经理横截面、同类定位、相似基金、收藏夹、研究笔记、监控规则、最近研究、审计记录、权限隔离、数据质量、任务暂停/继续/取消、限频冷却和增量更新。

## 数据兼容

继续使用 `~/.fundscope/fundscope.db`。V8 系列和 V9.0.0 已采集数据无需重新抓取。

# FundScope Product Definition

## Core questions

FundScope is designed to answer three research questions:

1. What has this fund changed?
2. Is that change consistent with the manager's longer-term behavior?
3. Are other institutions moving in the same direction?

## Main workflow

Market Pulse
→ Fund Research
→ Portfolio Evolution
→ Manager Context
→ Institutional Consensus

## What FundScope does not claim

A change in portfolio weight does not automatically equal active buying or selling.

Weight can change because of:
- security price movement
- fund subscriptions/redemptions
- portfolio transactions
- changes in total NAV
- disclosure-scope differences

The interface therefore separates disclosed-weight changes from transaction evidence.

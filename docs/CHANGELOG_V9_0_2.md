# FundScope V9.0.2 更新记录

## 目标

V9.0.2 是针对 V9.0.1 实际运行反馈的稳定性与性能修复版，重点处理大数据库下的交互延迟、分析模块长期等待、搜索信息层级和市场页短暂超时后的恢复体验。

## 修复

### 收益缺口

“补齐分析数据”回到收益缺口空状态内部，使用正常文档流与居中布局，不再使用负 margin 悬浮定位。

### 同类定位与持仓相似

- 分析范围收敛到实际需要的报告期。
- 持仓相似先按共同证券筛候选基金。
- 增加独立加载、失败与重试状态。
- 横截面结果增加短期缓存。

### SQLite 与页面性能

- Schema 每进程仅初始化一次。
- 增加持仓报告期相关索引。
- 基金研究按 Tab 懒加载。
- Return Gap 价格批量查询。
- 市场脉搏与研究探索限制历史读取范围。
- 普通基金详情不再隐式触发远程资料请求。

### 搜索

- 隐藏基金经理内部 ID。
- 公开代码与名称重新分层。
- 增加搜索防抖、加载状态、Hover 和空状态。

### 市场脉搏

- GET 临时错误自动重试一次。
- 保存最近一次成功结果作为短暂超时兜底。
- 错误状态缩为标准卡片，并提供重新加载。

### 时间轴

季度轨道默认展示当前报告期附近 12 个季度；长期历史通过报告期跳转访问。

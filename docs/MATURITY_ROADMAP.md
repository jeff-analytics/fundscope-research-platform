# FundScope 成熟化路线

V5 已完成：持久化数据目录、增量采集、后台任务进度、数据质量、数据快照、基金经理双目录选择器、正式品牌标识。

下一阶段优先级：
1. Fund Master：A/C/E 等份额归并到统一基金主体。
2. Manager Tenure：记录基金经理任职起止时间，支持历史归因。
3. Report Model：区分季报、半年报、年报及披露范围。
4. Security Master：统一 A 股、港股、海外证券编码与行业分类。
5. 数据源 Provider 冗余：关键数据至少保留两个可替代来源。
6. Watchlist / 最近查看 / 保存研究工作区。
7. 报告导出与可分享研究链接。
8. 后台任务并发控制、指数退避、断点恢复和预计剩余时间。
9. 自动数据质量告警与异常样本定位。
10. CI/CD、前端 E2E 测试和生产数据库迁移方案。

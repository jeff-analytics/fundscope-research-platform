# FundScope V9 产品架构

## 核心用户

### 个人投资者
关注机构配置正在向哪里集中、哪些共识正在形成或退潮，以及具体由哪些基金推动。

### 研究员
快速完成基金季度调仓、持仓持续性、风格漂移、基金经理跨产品行为和同类定位分析。

## 关键使用流程

### 流程 A：从市场发现到基金研究
研究探索 / 证券 → 发现“新共识”证券 → 打开证券持仓抽屉 → 查看增配/减配基金 → 进入基金研究 → 查看调仓变化、同类定位和风格漂移 → 加入收藏 / 创建监控。

### 流程 B：从基金经理发现到产品研究
研究探索 / 基金经理 → 筛选高漂移、高换手、风格一致或跨产品分散 → 进入基金经理研究 → 查看管理产品 → 下钻单基金 → 保存研究笔记。

### 流程 C：持续研究
任一研究页 → 收藏对象 → 我的研究记录判断 → 创建指标监控 → 新持仓或市场数据写入后自动重新判断 → 触发记录 → 回到对象复核。

## 可解释性原则

- 横截面标签基于明确统计阈值。
- 同类定位展示百分位、P25、中位数、P75。
- 相近基金使用当前展示指标的标准化距离，不输出黑箱评分。
- Sankey 表达配置迁移估计，不解释为逐笔资金流向。
- 基金经理横截面按当前产品集合口径，不虚构历史任职归因。

## 数据持久化

V9 继续使用：
- Windows `C:\Users\<用户名>\.fundscope\fundscope.db`
- macOS/Linux `~/.fundscope/fundscope.db`

新增 Workspace 数据表会自动创建，不要求重新采集历史持仓。

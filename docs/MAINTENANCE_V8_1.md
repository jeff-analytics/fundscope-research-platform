# FundScope V8.1 维护说明

## 永久数据

真实数据默认存放在：

`~/.fundscope/fundscope.db`

代码版本目录可以删除，数据库目录不要删除。

## 升级版本

后续 V8.2、V9 等版本应继续遵守：

1. 不把真实数据库放进 ZIP。
2. 不把版本号写进数据目录。
3. 数据表新增字段通过 `ensure_schema()` 增量迁移。
4. 新采集接口必须接入 TaskContext checkpoint。
5. 新网络数据源必须定义自己的并发与限频策略。
6. 前端不要直接暴露线程数，统一使用稳健 / 标准 / 极速策略。

## 端口

开发模式固定使用：

- API: 8000
- Web: 5173

Windows 启动器只会清理命令行包含 FundScope 路径的旧监听进程。若端口属于其他项目，启动器会退出。

## 出现 514 时

V8.1 起无需关闭 API。

页面会进入“冷却中”，系统停止新请求并自动恢复。如果希望暂时停止任务，点击暂停即可。

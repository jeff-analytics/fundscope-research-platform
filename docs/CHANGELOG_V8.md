# V8.0.0

- 默认研究池改为主动偏股，彻底移除债券、二级债、可转债、指数、ETF、联接等产品。
- 基金经理目录同步过滤，只保留至少管理一只主动偏股基金的经理。
- 持仓时间范围新增“最近 5 年”和“成立至今”。
- 基金研究页新增“补齐历史”，可单只基金按成立日期补全历史持仓。
- 基金档案缓存新增标准化 `inception_date`。
- 数据中心增加采集计划预估。
- 采集速度提升为全局采集模式：4 / 8 / 12 路。
- 市场报告使用小规模并发。
- Security Master 改用批量 A 股行情 + 行业板块成份映射，大幅减少逐证券请求。
- Security Master 分为“快速主表”和“深度补齐”。
- 新增“日常增量更新”任务。
- 已知无持仓导致的 AKShare KeyError 归类为 empty，减少误报错误。
- 持仓新增报告类型和披露范围字段。
- 机构共识表的趋势折线改成紧凑方向箭头和净变化数字。
- 后端测试 21 项通过。

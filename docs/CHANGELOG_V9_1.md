# FundScope V9.1.0 更新记录

V9.1.0 是面向 GitHub 发布前的研究体验收口版本，重点处理同类研究视觉、相似度解释、数值精度和机构共识的时间探索能力。

## 同类定位
- 六项同类指标重新排版，减少文字拥挤。
- 当前值与横截面百分位分离显示。
- 保留 P25 / P50 / P75，全部按两位小数显示。
- 解释信息收进原生悬停提示，页面不再长期占用一行说明。

## 持仓相似
- 原“相似度构成”改为“相似度拆解”。
- 点击散点或表格基金后，右侧真实展示持仓相似度、权重重合、证券集合重合。
- 增加共同证券列表及进入目标基金的入口。
- 三项指标保持独立，不合成为黑箱评分。

## 数值展示
- 调仓、风格、收益缺口、同类比较、相似度、行业迁移等界面统一控制到两位小数。
- ECharts 行业变化与相似度 Tooltip 显式格式化，避免出现二进制浮点尾差。

## 机构共识
- 支持任意当前报告期与更早基准报告期比较。
- 报告期选择范围扩展到最近 24 个季度。
- 历史窗口支持最近 4 / 8 / 12 / 20 季。
- 新增机构共识地图、共识演化、行业配置变化、行业参与度历史。
- 新增新共识、共识形成、持续增强、高共识、高位退潮、共识减弱、稳定状态筛选。
- 巨型 Sankey 不再作为机构共识主视图。

## 发布
- 版本号升级为 v9.1.0。
- 保持现有 `~/.fundscope/fundscope.db` 数据兼容，不要求重新采集。
- 发布包继续排除数据库、虚拟环境、 node_modules、构建缓存和日志。
